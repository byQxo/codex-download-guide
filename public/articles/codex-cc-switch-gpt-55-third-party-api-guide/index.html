Codex接入GPT-5.5教程：使用CC-Switch配置第三方API

原创 已于 2026-06-06 15:38:14 修改 · 3.3w 阅读 · 42 · 35 · CC 4.0 BY-SA版权
文章标签： #Codex教程 #GPT-5.5配置教程 #Codex接入第三方API #CC-Switch使用教程 #OpenAI兼容接口配置 #GPT-5.5模型调用 #AI编程工具配置 #Codex客户端设置

最近不少开发者都在体验 OpenAI 推出的 Codex 编程客户端，不过官方接口在部分场景下配置起来相对复杂。

前几天有朋友问我：

能不能让 Codex 直接调用第三方 OpenAI 兼容接口，从而使用 GPT-5.5 模型？

研究了一下发现其实非常简单，只需要借助 CC-Switch 进行接口代理管理即可。

本文详细介绍从注册 API 平台到配置 CC-Switch，再到 Codex 成功调用 GPT-5.5 模型的完整流程。

一、效果展示

配置完成后：

  • Codex正常启动
  • 支持调用第三方OpenAI兼容接口
  • 使用GPT-5.5模型
  • 无需复杂命令行配置
  • 支持后续切换多个供应商

整体架构如下：

Codex客户端
                  │
                  ▼
            CC-Switch
                  │
                  ▼
            第三方API平台（api.yudidc.cc）
                  │
                  ▼
            GPT-5.5模型

二、软件下载

Codex客户端

下载地址：

https://download.yudidc.cloud/

CC-Switch

下载地址：

软件下载地址
CC-Switchhttps://github.com/farion1231/cc-switch/releases/latest

下载后完成安装即可。

三、注册API平台

首先访问：

https://api.yudidc.cc

完成账号注册。

注册成功后登录后台。

四、创建API Key

进入：

https://api.yudidc.cc/console/token

可以看到 API Key 管理页面。

第一步

点击右上角：

创建API密钥

如下图所示：

创建API密钥

第二步

名称随便填写即可。

例如：

codex

或者：

gpt55

均可。

第三步

点击右下角：

保存更改

按钮。

保存成功后会新增一条 API Key。

第四步

找到刚刚创建的 Key。

点击右侧：

复制

按钮。

复制保存好这个 Key，后面需要使用。

示意：

API Key
            sk-xxxxxxxxxxxxxxxxxxxxx

五、配置CC-Switch

打开 CC-Switch。

第一步

点击顶部：

OpenAI

图标。

第二步

点击右上角：

+

新增供应商。

第三步

填写供应商信息。

预设供应商

选择：

自定义配置

供应商名称

填写：

api.yudidc.cc

API请求地址

填写：

https://api.yudidc.cc

API Key

填写刚刚复制的 Key。

格式类似：

sk-xxxxxxxxxxxxxxxx

配置示例：

配置项内容
预设供应商自定义配置
供应商名称api.yudidc.cc
API请求地址https://api.yudidc.cc
API Key刚刚复制的Key

第四步

点击右下角：

添加

按钮。

完成供应商创建。

六、切换到 api.yudidc.cc 渠道

回到 CC-Switch 主界面。

找到刚刚创建的：

aisz

渠道。

切换为当前使用渠道。

示意：

○ OpenAI

            ● aisz

确保当前选中的是：

aisz

七、重启Codex客户端

配置完成后。

关闭 Codex。

然后重新启动 Codex。

退出Codex
                  ↓
            重新打开Codex

这样 Codex 就会重新读取当前接口配置。

八、验证是否配置成功

打开 Codex 后直接发送一个测试问题：

你好，请介绍一下自己

或者：

帮我写一个Vue组件

如果能够正常返回结果，则说明配置成功。

此时实际调用的已经是：

GPT-5.5

模型。

九、常见问题

1、Codex没有返回内容

检查以下几项：

  • API Key是否复制完整
  • API地址是否填写正确
  • 当前是否切换到 api.yudidc.cc 渠道
  • 是否重启Codex客户端

2、提示认证失败

重新创建一个新的 API Key。

再次复制粘贴。

确保没有多余空格。

3、修改配置后没有生效

建议：

切换一次渠道
            ↓
            关闭CC-Switch
            ↓
            重新打开
            ↓
            重启Codex

通常即可解决。

十、总结

本文介绍了如何通过 CC-Switch 为 Codex 客户端 接入第三方 OpenAI 兼容接口，并成功调用 GPT-5.5 模型。

整体流程非常简单：

注册平台
                ↓
            创建API Key
                ↓
            配置CC-Switch
                ↓
            切换渠道
                ↓
            重启Codex
                ↓
            使用GPT-5.5

对于经常使用 AI 编程工具的开发者来说，这种方式能够更加灵活地管理多个模型供应商，并且后续切换接口也更加方便。

如果你也在使用 Codex，不妨按照本文步骤配置体验一下。
